# 过滤器

Nushell 的一个主要目标是能够在管道中轻松处理结构化数据。Nushell 包含了一组丰富的命令，被称为“过滤器”，就是为满足这些需求而设计的。

本指南在下面列出了过滤器命令的示例。要查看当前被归类为过滤器的命令列表，你可以运行：

```nu
help commands | where category == filters
```

## 过滤器 vs. 流程控制语句

虽然使用 `for` 或 `while` 这类“传统”流程控制语句当然也能修改结构化数据，但过滤器通常更方便，而且（往往远）更高效。更多信息请参见[《Nushell 之书》的变量章节](../../../book/variables.md#在可变和不可变变量之间进行选择)。
