# 语言参考指南

在本节中，我们整理出了语言参考指南的一个开端。

这里的想法是提供一个大纲，让人们可以在自己熟悉的领域以“小”的方式作出贡献。

还有一些主题需要补充，我也看到一些重复的部分需要清理。我在写这份文档时曾试图大致参照 [https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/About](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/About) 和 [https://phel-lang.org/documentation/getting-started/](https://phel-lang.org/documentation/getting-started/) 的写法。也许还有我们更愿意参照的其它文档，如果你有的话，请提出来。

希望能先提供一点说明文字作为背景，然后给出大量用法示例。
