# Nu 编程

本章更深入地介绍 Nushell 作为一门编程语言的细节。
每个主要的语言特性都有自己的一节。

就像大多数编程语言允许你定义函数一样，Nushell 为此使用[自定义命令](custom_commands.md)。

你可能在其它 shell 中习惯使用[别名](aliases.md)。
Nushell 的别名工作方式类似，并且它是编程语言的一部分，而不仅仅是一个 shell 特性。

常见的操作，例如加法或正则搜索，可以用[运算符](operators.md)完成。
并非所有数据类型都支持所有操作，当出现不匹配时，Nushell 一定会让你知道。

你可以把中间结果存储到[变量](variables.md)中。
变量可以是不可变的、可变的，或者是解析时常量。

[控制流](control_flow.md)命令，例如 `if`、`match`、`for` 和 `try`，决定哪些代码运行以及运行多少次。

接下来的三节旨在组织你的代码：

[脚本](scripts.md)是最简单的代码组织形式：你只需把代码放进一个文件并 source 它。
不过，你也可以使用“特殊的” `main` 命令，让脚本作为带命令行签名的独立程序运行。

借助[模块](modules.md)，就像在许多其它编程语言中一样，你可以用更小的片段组合你的代码。
模块让你定义公开接口与私有命令，并且可以从中导入自定义命令、别名和环境变量。

[Overlay](overlays.md)建立在模块之上。
通过定义一个 overlay，你把模块的定义带入一个可替换的“层”中，该层会叠加在其它 overlay 之上。
这启用了诸如激活虚拟环境、或用自定义变体覆盖一组默认命令等特性。

标准库还提供了一个[测试框架](testing.md)，如果你想证明你的可复用代码能完美工作；而当它不能时，你可以[在编辑器的调试器中单步执行](debugging.md)。
